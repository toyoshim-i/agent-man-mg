# Start here

You are making motion graphics or live visuals. The work happens in two phases.

- **Phase 1, Idea: what to make.** Excellent work starts from a way of thinking that earlier
  makers found, held up against the conditions of today. Knowing more effects does not help
  here; knowing what earlier work was *for* does.
- **Phase 2, Craft: how to make it well.** Mood written as numbers, hard limits on choices, a
  structure in time, a finished image, and honest critique of your own output.

Skipping Phase 1 gives polished but ordinary work. Skipping Phase 2 gives a good idea, badly made.

## The procedure

Do every step, in order. Write each step's output down (in your reply or a `notes.md`)
before starting the next; later steps read it. Short is fine. Skipped is not.

Phase 1: Idea

1. **Brief.** Turn the request into a spec with numbers. Read [Brief](../process/1-brief.md).
2. **Concept.** Pick ways of thinking from the [Ideas](../idea/ideas.md) index, hold each against
   [Now](../idea/now.md), and keep the one that only makes sense today. Read
   [Concept](../process/2-concept.md).

Phase 2: Craft

3. **Design sheet.** Palette, type, shape and motion language as numbers. Read
   [Design sheet](../process/3-design.md), which sends you to the [Mood map](../table/mood-map.md)
   and a [look](../look/swiss.md).
4. **Structure.** Sections, energy curve, timing chart in seconds. Read [Structure](../process/4-structure.md).
5. **Build.** Static frame first, motion second, finish last. Read [Build](../process/5-build.md).
6. **Review.** Render frames, run the checks, `explain` every failure, fix. At least two
   rounds. Read [Review](../process/6-review.md).

## Hard limits (always on)

- One idea per piece. If it needs "and" to describe, cut one half.
- At most 3 colors plus neutrals. Exactly one accent. See [Color](../principle/color.md).
- At most 2 typefaces. See [Typography](../principle/typography.md).
- One motion language: one easing family, one speed range. See [Easing](../principle/easing.md).
- No linear interpolation between states. Linear is only for constant drift and spin.
- One focal point at any moment. See [Hierarchy](../principle/hierarchy.md).
- Finish pass is mandatory: anti-aliasing, dither, grain. See [Finish](../principle/finish.md).
- Never more than 3 full-screen flashes per second. See [Flash safety](../vj/vj-safety.md).

## How to use this tool

- `agent-man-mg guide` lists every page. `guide <topic>` reads one.
- `agent-man-mg explain <symptom>` diagnoses what you see: `banding`, `jitter`, `muddy-palette`.
- `agent-man-mg search <words>` finds pages when you do not know the id.
- Read a page before you write that part of the work, not after.
- Every page gives defaults. Use the default unless the brief gives a reason not to, and
  write the reason down.
