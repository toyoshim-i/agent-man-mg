# Brutal type

Type as architecture. Letters fill and overflow the frame, cut on every bar, with one
violent color. It reads as confidence through excess, so it still needs strict limits.

## Design sheet

```text
look:      brutal-type
palette:   acid-club or mono-op
type:      Anton or Archivo 900 (wdth 125); 1/2 to 1.5x frame height, cropped by the frame
shapes:    full-bleed bars, thick rules (1 to 3% of height), no curves
motion:    hard cuts; outQuint at 0.6x speed; scale punch 115% to 100% on hits
speed:     factor 0.6; drift 0
density:   0.7
texture:   grain 0.05; optional glitch bursts on snares
camera:    static, impact shake 1.5% on drops
```

## Signature moves

- One word per beat, each filling the frame, cut on the beat.
- Text crops: letters enter from beyond the frame edge and stop half off-screen.
- Inversion on the drop: background and main swap for one bar (not every beat).
- Repeated word in rows, offset by row, scrolling at different speeds.

## Don't

- No more than one accent color. The accent is a weapon; use it on one word.
- No soft easing, no fades longer than 2 frames.
- No inverted full-frame flashes faster than 3 per second:
  [strobe-risk](../rule/strobe-risk.md).
